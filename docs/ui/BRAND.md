# Cooper Cardinal brand notes

Source: https://www.coopercardinal.com/, reviewed 2026-10-30.

The public site is a WordPress marketing page. Its useful marks are the wordmark and a white logo file meant for a dark field:

https://www.coopercardinal.com/wp-content/uploads/2019/01/CC-logo-ferenzTag_white_400.png

There is no published color system, type specimen, or logo for a light background. The desk therefore uses a text mark, “CC”, in the header instead of stretching that white logo onto a light panel.

Color taken from the existing desk, used as an accent only:

- Ink `#1c1917`
- Burgundy `#7f1d2c` for links, the primary button, and the severe score
- Gold `#92400e` for the elevated score band and the “before you call” rule

The page background is warm stone, not burgundy. Large burgundy fills are not part of this pass. Dark mode inverts the stone scale and lightens the accent so it stays readable.
